Neues Schlüsselpaar erzeugen

Erzeugt ein RSA-4096-Schlüsselpaar lokal im Browser. Der Private Key wird als private-key.pem heruntergeladen, der Public Key erscheint darunter in einer Zeile zum Kopieren. Den Private Key sicher aufbewahren: Geht er verloren, sind alle Antworten unwiederbringlich verloren.

Public Key (einzeilig)

Diesen Wert als PUBLIC_KEY setzen: bei Cloudflare mit yarn wrangler secret put PUBLIC_KEY und einfügen, lokal in .dev.vars hinter PUBLIC_KEY=. Der Public Key ist nicht geheim.
